1. 遊戲概述
遊戲名稱：《拉耙耙》

核心特色：融合了「拉霸機隨機生成 / 符號牌庫構建（Slot Deck-Building）」與「地牢走格子探索（Grid-based Roguelite Crawler）」的雙核心玩法。
綜合強化亮點：
告別敷衍 Emoji，全純 Canvas 2D 復古像素美術：包含四大職業、全怪物 Boss、道具、拉霸符號與傳奇遺物之專屬像素繪製。
實體街機機械拉霸機：具備金屬 3D 搖桿物理下拉動畫、彩燈跑馬燈輪播、三軸獨立減速停輪與回彈震顫（Recoil Bounce），以及 777 大獎全螢幕金幣噴泉瀑布。
Web Audio API 8-Bit 晶片音樂與音效引擎：內建自製多聲道地牢循環背景音樂（BGM：方波旋律 + 三角波低音 + 噪聲爵士鼓）與完整打擊/拉霸/金幣/大獎音效，支援雙獨立靜音控制。
黑市流浪行商營地與牌庫提純：深入地牢可遇見神祕商人，消耗金幣提純牌庫、購買強效符號與盲盒遺物。
交付規格：單一檔案 index.html（CSS、JavaScript 完全自包含，不依賴任何外部圖檔、音效或第三方庫），支援雙擊本機離線遊玩與 GitHub Pages 線上公開遊玩。

4. 拉霸符號系統與牌庫構建 (Slot Symbols & Deck-Building)
4.1 符號類型與像素設計
怪物符號 (Enemies)：

吸血蝙蝠 (Bat)：展翅撲翼黑紫蝙蝠，露出尖牙與血紅雙眼。
哥布林盜賊 (Goblin)：尖耳綠皮小偷，手持鋸齒短匕首。
骷髏射手 (Skeleton)：慘白頭骨與肋骨架，手持長弓拉弦待發。
貪婪寶箱怪 (Mimic)：偽裝成寶箱，箱蓋咧開滿嘴利齒與紫色長舌。
熔岩幼龍 (Lava Drake)：赤紅鱗片噴火幼龍，長角且雙目燃燒金焰。

道具符號 (Items)：金幣、美味披薩（回血/食物增傷）、生命藥水、力量合劑、智慧精華、黃金寶箱、奇蹟仙豆（拾取獲免死復活）。
拉霸標誌 (Slot Symbols)：黃金鈴鐺、白金 BAR、幸運 7、奧義卷軸。
地形標誌 (Environment)：堅硬岩石（阻擋道路，可擊碎摧毀）、下樓樓梯（通往下層傳送門）、流浪行商（黑市營地）。

5. 流浪行商黑市營地 (Black Market Merchant)
在地牢特定層數（第 3 層、第 7 層）地磚上隨機生成流浪行商，玩家亦可隨時點擊狀態欄 [🛒 呼叫行商] 開啟交易。
交易品項：
秘制生命藥水 (25 金幣)：立即恢復 45 點生命值。
黑市牌庫提純 (30 金幣)：從符號牌庫中永久抹除 2 個雜魚符號（史萊姆/岩石/蝙蝠，保證最低 5 張牌底）；若牌庫已無雜魚則轉為洗練獲 +15 最大 HP！
灌鉛幸運 7 符號 (40 金幣)：將 2 個幸運 7 強效符號注入牌庫。
黑市遺物盲盒 (55 金幣)：隨機獲取一件未持有的傳奇遺物；若遺物已全數收藏則轉化為遺物精華（全屬性+2與生命全滿）。
