# 🏰 《拉耙耙》(La-Pa-Pa) - 網頁版

> 🎮 **一款融合「機械拉霸機隨機生成」與「牌庫構築」的 Roguelite 地牢冒險網頁遊戲。**  
> 採用 **Vibe Coding** 理念，全端單一 `index.html` 實現，零任何外部圖檔/音訊相依，內建 HTML5 Canvas 2D 像素渲染與原生 Web Audio API 8-bit 晶片音樂合成引擎。

---

## 🌟 遊戲核心玩法與綜合加強亮點

1. **告別敷衍 Emoji，全純 Canvas 2D 復古像素美術 (Procedural Pixel-Art Graphics)**：
   - 拒絕單調文字表情符號！所有角色、怪物、Boss、道具、拉霸符號與傳奇遺物皆採用 Canvas 2D 純程式碼逐像素繪製。
   - 包含四角動態火炬照明、動態呼吸浮動、地牢石板磚紋理、暗黑暗角 (Vignette) 與受創畫面震顫 (Screen Shake)。
2. **實體街機機械拉霸機 (Arcade Mechanical Slot Cabinet)**：
   - 右側配備金屬實體 3D 搖桿物理下拉動畫，點擊或拉動皆有機械齒輪囓合與卡榫聲響。
   - 霓虹跑馬燈彩燈 (Chaser Bulbs) 動態循環輪播。
   - 三軸輪盤**真實抽取玩家「牌庫符號」滾動**，牌庫提純能切實大幅提升大獎連線期望值！
   - 探索房間中可隨時點擊【🎰 幸運拉霸 (25G)】或拉桿花費 25 金幣搏手氣，獲取大獎增益而不重置當前房間地圖進度。
   - 湊齊 777、3 鈴鐺、3 BAR、3 奧義、3 寶箱或 3 靈藥引爆全螢幕「金幣瀑布噴泉」慶祝特效！
3. **Web Audio API 8-Bit 晶片音樂與音效引擎 (Chiptune Audio Synthesizer)**：
   - **原創循環背景音樂 (BGM)**：四聲道和聲（方波主旋律 + 三角波低音 + 噪聲爵士鼓），營造純正紅白機/街機冒險氛圍。
   - **打擊感音效**：拉桿齒輪聲、轉軸回彈喀噠聲、腳步聲、揮劍劈砍、雷霆暴擊、怪物碎裂、金幣叮噹響與大獎號角。
   - 支援 BGM 與 SFX 獨立靜音切換開關。
4. **四大英雄職業體系 (Hero Classes)**：
   - ⚔️ **鐵壁戰士 (Warrior)**：高 HP 與護甲，特有「飽食機制」（吃披薩食物大幅增傷），奧義【破陣十字斬】十字破甲群攻並獲取堅盾。
   - 🧙 **奧術法師 (Mage)**：高智力，法術符號共鳴，奧義【極光連鎖】穿透虛空隨機雷擊 3 名敵人。
   - 🎰 **千面賭徒 (Gambler)**：超高幸運值與暴擊率，777 中獎率大幅提升，奧義【天命重骰】將盤面怪物強制轉化為黃金金幣或寶箱。
   - 🗡️ **放逐罪人 (Sinner)**：0 護甲自殘狂化流派，殘血攻擊力狂飆，奧義【苦痛盛宴】消耗 HP 引爆劇毒血爆。
5. **流浪行商黑市營地與牌庫提純 (Merchant & Deck Purge)**：
   - 地牢探索可偶遇神祕行商，或於狀態面板隨時呼叫行商。
   - 可花費金幣購買秘制生命藥水、盲盒遺物、灌鉛符號，更可進行「黑市牌庫提純」永久消除雜魚弱小符號（史萊姆/岩石/蝙蝠），使大獎機率暴增！全遺物集齊時盲盒自動轉化為全屬性提升的遺物精華。
6. **10 層深淵地牢挑戰、Combo 增傷與史詩 Boss**：
   - 連擊系統（Combo）提供額外攻擊傷害加成（每連擊 +0.8 傷害），並在通關時納入最高連擊計分！
   - 第 5 層首領【賭場巨蛙大亨】Boss 阻擋去路，擊敗後方會顯現下層樓梯。
   - 第 10 層終極魔王【遠古暗黑魔龍】嚴陣以待，成功斬殺魔龍直接引爆通關勝利 (Victory)！

## 🕹️ 操作方式說明

- **電腦鍵盤**：
  - 移動 / 攻擊：`W` `A` `S` `D` 或 方向鍵 `↑` `↓` `←` `→`
  - 施放奧義技能：`Space`（空白鍵）
  - 查看牌庫：點擊右上角 `[🎴 牌庫]` 按鈕
  - 切換音效 / BGM：點擊右上角 `[🎵 BGM]` 與 `[🔊 音效]` 按鈕
  - 呼叫黑市行商：點擊屬性欄 `[🛒 呼叫行商]` 按鈕
- **滑鼠操作**：
  - 點擊地牢網格中角色相鄰的格子即可移動、拾取或攻擊。
  - 點擊右側機械拉桿或【幸運拉霸 (25G)】按鈕即可啟動拉霸，博取大獎。
- **手機 / 平板觸控**：
  - 右下方提供專屬觸控十字虛擬鍵盤與圓形技能鍵（具備全狀態防誤觸防重入鎖）。
